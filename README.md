# OL BORÉLER

Arcade verticale ispirato alla tradizione bergamasca della fluitazione del legname.

## Primo prototipo
Apri `index.html` in un browser moderno, anche su smartphone.

- Il boscaiolo resta nella parte bassa dello schermo.
- Il fiume e gli ostacoli scorrono verso il basso.
- Movimento laterale con pulsanti touch o frecce della tastiera.
- Ostacoli: massi, tronchi e rapide.
- Velocità progressiva, vite, punteggio e record locale.
